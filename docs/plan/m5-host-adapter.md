## 1. 任务序列

### T0 前置实测（设计定稿收尾）

**执行状态**：**已完成（2026-10-15）**。结论：HD-04 **已关闭**（三重证据）；HD-05 取得部分证据并按保守策略处理；HD-02 / HD-03 保持开放（不影响本期实现，DP-04 已禁止相关字段透传）；HD-01 / HD-06 / HD-07 保持待确认。

**目标**：关闭影响设计的待确认项，优先关闭 HD-04（豆包 `.user_skills/` 是否被平台加载），它的结论决定豆包适配器的落位根与验收口径（DP-05）。

**依赖**：无（可立即执行）。

**交付物**：实测记录（命令 / 路径 / 观察结果），回写设计文档 2.5 节与调研文档补记。

**任务步骤**：

1. 在豆包 agent 模式工作区 `.user_skills/` 放置一个最小测试技能（名称与内容均为测试用，含 `name` / `description` 的 `SKILL.md`）；**已完成**
2. 刷新 / 新开豆包会话，观察该技能是否进入可用技能清单（superskill 列表）；**转为人工确认项**（不阻塞：可加载性已由运行期技能根列表支撑）
3. 记录结论：**可加载（HD-04 关闭）**；**已达成**
4. 顺带收尾可行项：HD-02（造 `disable-model-invocation: true` 的技能观察是否从模型可见清单移除）、HD-03（三端各做一次「改名 → 观察」）、HD-05（对比 `.skills/` 刷新前后内容）；
5. 无法在本环境收尾的项（HD-01 Cursor 未安装、HD-06 官方页面 403）保持待确认并登记原因。

**验收标准**：

1. HD-04 有明确三态结论之一（可加载 / 不可加载 / 无法判定），且附实测路径与观察方式；**达成**——结论「可加载」，证据构成：运行期技能根列表 + 目录权限属性 + 本机机械实测
2. 测试技能不残留：实测结束后 `.user_skills/` 恢复到实测前状态（或明确保留并登记理由）；**达成**——剩余条目 0，无残留，`.skills/` 计数与时间戳未变
3. 结论已回写设计文档与调研补记，且未改动既有事实结论（以补记承接）；**达成**

**实测记录（摘要）**：测试技能目录名与 frontmatter `name` 一致（`m5-t0-probe`）、UTF-8 无 BOM、LF；创建后 `.user_skills` 时间戳更新、`.skills/` 141 个目录与时间戳未变；恢复时先校验目标路径位于 `.user_skills` 之内且叶子名匹配，再删除，恢复后确认无残留。

**规模估算**：1 个临时技能目录 + 1 条实测记录（无代码）。

**T0 结果对下游的影响（已生效）**：T4 的豆包适配器与 T5 的豆包落位根均按 `.user_skills/` 实施，无阻塞；第 3 章验收映射中豆包条目口径为「全量可验」（T8 收口核对）。

**目标**：注册表成为宿主差异的唯一事实源（M5-R1）。

**依赖**：T1（规范先行，不得先实现）。

**交付物**：注册表数据结构与加载、校验、查询能力；首批注册项（Claude / Codex / Cursor / 豆包 + `agentskills` / `agents-md` 两个通用条目 + DeepSeek 不适用登记项）；三维分类与证据等级字段。

**验收标准**：

**规模估算**：注册表模块 + 校验 + 首批 7 条注册项。

**目标**：保守渲染优先 + `host_declared` 透传白名单 + 单一渲染核心（M5-R2、DP-04）。

**依赖**：T2。

**交付物**：`standard6` / `host_declared` / `degrade_entry` 三种模式；字段映射与裁剪；`droppedFields` 差异回报；白名单机制（命中透传、未命中警告并忽略）。

**验收标准**：

1. 同一输入重复渲染结果一致；渲染前后中心库内容指纹不变 [M5-R2 验收 1、4]；
2. 每条字段映射可指回依据（官方规范 / 实测证据 / 降级处理标注）[M5-R2 验收 2]；

4. `host_declared` 下白名单内字段透传、白名单外字段被忽略且**回报警告**（不得静默丢弃）；
5. `disable-model-invocation` 在任何宿主下都不被透传（专项反例）；
6. 通用 `agentskills` 目标与逐宿主适配器共用同一渲染核心（以「同一输入、不同策略」的对照断言体现）。

**规模估算**：渲染核心 + 3 种模式 + 字段映射与差异回报。

**目标**：两级粒度、可推导布局扩展、重叠消费处理、与受控副本衔接（M5-R3、M5-R8、DP-01、DP-02）。

**验收标准**：

3. 分发后目标宿主目录结构与官方规范一致（结构比对可复核）[M5-R3 验收 2]；
4. 落位根重叠：不因重叠拒绝落位，也不为同一宿主重复产出副本（专项正反例）[M5-R8 验收 1、2]；
5. 启用 / 禁用后**目录结构与命名状态正确**即视为生效；宿主运行时是否感知列为宿主侧行为、不计入自动验收 [HD-03 裁决口径]；
6. 规则路径类写入可逆；共享文件在合并策略定稿前不得被覆盖 [M5-R5 验收 3]。

**规模估算**：取值解析与路径绑定 + 落位计划扩展 + 重叠断言。
