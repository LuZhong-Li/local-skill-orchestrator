# 里程碑计划模板

## 概述

把大项目拆解成可执行的里程碑和任务，明确依赖关系和时间节点。

## 使用场景

- 项目立项排期时
- 迭代规划时
- 进度跟踪时

## 模板结构

### 1. 项目概览

- 项目目标
- 范围边界
- 总工期

### 2. 里程碑

| 里程碑 | 目标日期 | 交付物 | 负责人 |
| ------ | -------- | ------ | ------ |
| M1     | 日期     | 交付物 | 负责人 |

### 3. 任务拆解

每个里程碑下拆成 3-5 个任务：

- [ ] 任务 1（负责人，工期）
- [ ] 任务 2
- [ ] 任务 3

### 4. 依赖关系

- 前置依赖
- 外部团队依赖

### 5. 风险与缓冲

- 关键路径
- 预留缓冲时间
