# 代码评审检查清单

## 概述

标准化代码评审流程，确保每次提交都经过全面检查。

## 使用场景

- PR 创建后
- 代码合并前
- 技术债清理时

## 检查清单

### 功能正确性

- [ ] 代码是否实现了需求？
- [ ] 是否有边界情况处理？
- [ ] 错误处理是否完整？
- [ ] 日志是否足够排查问题？

### 安全性

- [ ] 是否有注入风险（SQL/命令/路径）？
- [ ] 用户输入是否经过校验？
- [ ] 敏感信息是否硬编码？
- [ ] 权限检查是否到位？

### 性能

- [ ] 是否有 N+1 查询？
- [ ] 是否有不必要的循环？
- [ ] 大数据量下是否会出问题？

### 可维护性

- [ ] 命名是否清晰？
- [ ] 函数是否过长？
- [ ] 是否有重复代码？
- [ ] 注释是否解释了"为什么"而不是"做什么"？

### 测试

- [ ] 新增功能是否有测试？
- [ ] 边界情况是否覆盖？
- [ ] 测试是否可独立运行？
