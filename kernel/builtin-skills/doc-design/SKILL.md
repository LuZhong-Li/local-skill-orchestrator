# 技术设计文档模板

## 概述

记录系统设计决策、架构结构和接口定义，便于后续维护和新人上手。

## 使用场景

- 新模块设计时
- 技术方案评审时
- 重构方案说明时

## 模板结构

### 1. 设计目标

- 要解决的技术问题
- 非目标（本期不做）

### 2. 架构概览

- 核心组件
- 组件间关系
- 数据流

### 3. 接口定义

| 方法 | 路径 | 入参 | 出参 | 说明 |
| ---- | ---- | ---- | ---- | ---- |

### 4. 数据模型

- 核心实体
- 字段说明
- 索引策略

### 5. 错误处理

- 错误码定义
- 重试策略
- 降级方案

### 6. 权衡与备选

- 为什么选这个方案
- 放弃了哪些方案
- 未来改进方向
